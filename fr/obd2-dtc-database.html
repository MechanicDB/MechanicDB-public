Formats

Chaque formule inclut les trois. CSV délimité par des barres verticales (UTF-8 BOM, compatible Excel). Apache Parquet avec compression Snappy — 92,0% plus léger (mesuré). Une base de données SQLite contenant les quatre tables avec la chaîne de jointure intacte.

La couverture, en toute transparence

Les 9 249 codes SAE universels s'appliquent à tous les véhicules, quelle que soit la marque. La couverture OEM n'est pas homogène — elle est la plus forte sur les marques du marché américain et certaines marques sont peu couvertes. La répartition complète par marque est publiée sur la page d'accueil pour que vous puissiez vérifier les marques qui vous intéressent avant l'achat plutôt qu'après. Chaque code publié remonte à une source versionnée ; un verrou de build rejette les codes inventés.
