Battery Charger DC Output Circuit

Diagnostic et explication technique
Code P0D20 sets when the onboard charger's HV-side DC output — the boosted/rectified voltage it delivers to the HV bus after the AC input stage — does not match the value or current the control module commands for the charge session. The most common physical causes are a degraded output filter capacitor or boost-stage component inside the charger, a corroded or loose HV-side output connection at the charger's junction, and an open condition in the DC output current-sense path. Because this circuit sits on the HV side of the charger between the AC input stage and the battery, confirming it requires the same lockout and zero-volt verification as any other HV-bus connector.
