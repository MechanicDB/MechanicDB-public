Código P0E30: High Voltage Fuse C

Explicación diagnóstica y técnica
Code P0E30 sets when the control module detects that the high-voltage system fuse has opened, removing power from the circuit it protects. The most common physical causes are an actual overcurrent/short-circuit event downstream of the fuse, a fuse that has fatigued and opened from age/vibration without a fault present, and a corroded fuse-holder connection.
