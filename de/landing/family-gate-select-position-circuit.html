Gate Select Position Circuit

Diagnose & technische Erläuterung
Code P0904 (Gate Select Position Circuit A) sets when the TCM sees an open, shorted, or implausible signal from the gate-select position sensor, or a fault driving the gate-select actuator, on a dual-clutch or automated manual transmission's shift-rail mechanism. This axis selects which shift-fork gate is engaged, so causes are sensor wear, a lost calibration, hydraulic/mechanical binding, or damaged wiring at the mechatronic connector.

Diese 21 Diagnose-Fehlercodes teilen einen Erkennungsmechanismus und einen Reparaturweg. Deshalb fasst MechanicDB sie in einer einzigen, redaktionell erstellten Fehlerfamilie zusammen, statt dieselbe Erklärung 21-mal zu wiederholen.
