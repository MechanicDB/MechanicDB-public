Formatos

Todos os planos incluem os três. CSV delimitado por barra vertical (UTF-8 BOM, compatível com Excel). Apache Parquet com compressão Snappy — 92,0% menor, conforme medido. Um banco de dados SQLite com as quatro tabelas e a cadeia de junção intacta.

Esquema

Quatro tabelas relacionais, normalizadas para bancos de dados e pré-unidas para notebooks.

Cadeia de junção: dtc_codes.code_id → diagnostic_fixes.code_id → replacement_parts.fix_id

Cobertura, com honestidade

Os 9.249 códigos universais SAE se aplicam a todos os veículos, independentemente da marca. A cobertura OEM não é uniforme: é mais forte em marcas do mercado norte-americano, e algumas marcas têm poucos códigos. O detalhamento completo por marca é publicado na página inicial para que você verifique as marcas que lhe interessam antes de comprar, e não depois. Cada código publicado remonta a uma fonte versionada; uma barreira no build rejeita códigos inventados.
